---

Use these links in emails based on the module a customer has. Current docs are hosted locally while testing:

- Base URL (local preview): `http://localhost:3001`
- Node.js / Express: `/docs/integrations/node-express#update-steps`
- .NET 8 (ASP.NET Core Minimal API): `/docs/integrations/dotnet-aspnet#update-steps`
- Java (Spring Boot Resource Server): `/docs/integrations/java-spring-boot#update-steps`

Guidance for emails:
- Registration (no modules): send only the welcome + Application ID.
- After module assignment: send the specific module link(s) above. If multiple modules are assigned, list each link, not the whole docs.
- Updates: notify only customers who have that module, include the module link with the `#update-steps` anchor, and summarize changes (major versions only for now).

Customer-to-module tracking: not found in this repo. Ensure the portal or CRM records which modules each customer owns so updates can be targeted correctly.
