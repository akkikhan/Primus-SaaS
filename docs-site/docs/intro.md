Primus lets you validate tokens from multiple issuers (Azure AD, LocalAuth, custom JWT) with the same middleware and claims model. Use these guides to get a working API in minutes and share them externally as your public integration playbook.

**What you get**

- Step-by-step setup for Node.js (Express) and .NET 8 (minimal API)
- Copy/paste configuration blocks using the `issuers` model already in the repo
- Email-friendly snippets plus a Docusaurus site you can host or export
