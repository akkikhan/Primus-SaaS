# 🎨 Color / Typography / Component Style Guide

**Design System:** "Primus Elite"  
**Framework:** Tailwind CSS (Custom Config)

---

## 1. 🎨 Color Palette

### Primary (Brand)
| Name | Hex | Usage |
| :--- | :--- | :--- |
| **Primus Blue** | `#2563EB` | Primary Buttons, Links, Active States |
| **Primus Dark** | `#1E40AF` | Hover States |
| **Primus Light** | `#DBEAFE` | Backgrounds, Accents |

### Functional
| Name | Hex | Usage |
| :--- | :--- | :--- |
| **Success** | `#10B981` | Success Toasts, Valid Status |
| **Error** | `#EF4444` | Error Messages, Delete Buttons |
| **Warning** | `#F59E0B` | Alerts, Pending Status |
| **Surface** | `#FFFFFF` | Cards, Modals |
| **Background** | `#F3F4F6` | App Background |

---

## 2. 🔤 Typography

**Font Family:** `Inter`, sans-serif.

| Style | Weight | Size | Line Height | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **H1** | Bold (700) | 32px | 1.2 | Page Titles |
| **H2** | Semibold (600) | 24px | 1.3 | Section Headers |
| **H3** | Medium (500) | 20px | 1.4 | Card Titles |
| **Body** | Regular (400) | 16px | 1.5 | Standard Text |
| **Small** | Regular (400) | 14px | 1.5 | Metadata, Hints |

---

## 3. 🧩 Components

### Buttons
*   **Primary:** `bg-blue-600 text-white hover:bg-blue-700 rounded-lg px-4 py-2`
*   **Secondary:** `bg-white text-gray-700 border border-gray-300 hover:bg-gray-50 rounded-lg px-4 py-2`

### Cards
*   **Standard:** `bg-white shadow-sm rounded-xl p-6 border border-gray-100`

### Inputs
*   **Default:** `border-gray-300 focus:ring-blue-500 focus:border-blue-500 rounded-md`
