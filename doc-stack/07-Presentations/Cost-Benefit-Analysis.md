# 📉 Cost-Benefit Analysis (Visuals)

**Context:** Decision to adopt Primus vs. Build Internal.

---

## Slide 1: The Cost of "Building It Yourself"

**(Chart: Bar Graph)**

*   **Bar 1 (Internal Build):** $150,000
    *   *Breakdown:* 3 Engineers x 3 Months.
*   **Bar 2 (Primus License):** $10,000
    *   *Breakdown:* Enterprise License + 1 Week Integration.

**Conclusion:** 15x ROI in Year 1.

---

## Slide 2: Maintenance Burden

**(Chart: Line Graph over 3 Years)**

*   **Line A (Internal):** Costs rise over time (Tech Debt, Security Patches, Upgrades).
*   **Line B (Primus):** Flat cost (Subscription includes updates).

**Insight:** Internal code becomes a liability. Primus code remains an asset.
